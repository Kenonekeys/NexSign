# Welcome to NexSign

NexSign is a modern IPA signing system built with Rust, WebAssembly, and a fully automated GitHub Actions pipeline.

It provides:

- A fast, browser‑based signing UI  
- A real iOS signing identity system  
- A binary CMS mobileprovision generator  
- A complete cert‑pack builder  
- A CI/CD signing workflow  
- A deployable website for end‑users
